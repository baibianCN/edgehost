⚡ EdgeHost

基于 Cloudflare Workers + php-wasm 的无服务器 PHP 虚拟主机。PHP 引擎编译为 WebAssembly 后运行在 Cloudflare 全球 300+ 边缘节点上，无需 VPS、无需容器、无需数据库。

PHP 版本8.3
运行时Cloudflare Workers (V8 Isolate + WebAssembly)
文件存储Cloudflare Durable Objects（单实例强一致，零配置）
支持文件类型.php / .html / .css / .js / .json / 图片 / 音频 / 视频 等
外网请求支持！http_get / http_post / http_json
发邮件支持！cf_mail()（在设置页配置 SMTP）
管理面板本界面（密码保护，/__admin）

支持的 PHP 特性

  • ✅ 完整的 PHP 语法：函数、类、数组、字符串、日期、正则、JSON
  • ✅ include / require 多文件站点
  • ✅ $_GET / $_POST / $_COOKIE / $_SERVER 请求上下文
  • ✅ 直连外网 API：http_get('https://api.xxx.com')
  • ✅ 发邮件：cf_mail('to@x.com','标题','内容')
  • ✅ 错误提示内联显示在页面中，方便调试
